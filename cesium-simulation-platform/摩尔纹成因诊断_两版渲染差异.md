# 摩尔纹成因诊断 —— 早期版无、当前版有的渲染差异

> 诊断日期：2026-09-14
> 结论先行：**摩尔纹不是"退化"，而是当前版把波动相位物理加进渲染后、缺乏屏幕空间抗混叠（LOD）的副作用**。早期版在数学上不可能出现摩尔纹——它的场里根本没有振荡空间结构。

---

## 一、为什么早期版不可能有摩尔纹

早期版着色器（`早期版本/.../sceneBuilder.js` L221-264）：

```
totalVel += dirS * mpsS;    mpsS = peakS · e^(−(β+βv)·gap)      // 纯包络，无相位项
mps = length(totalVel)                                           // 实矢量求和取模
```

- 每源贡献是 `平滑单调函数(r) × 径向单位矢量`，**没有 cos/sin 相位因子**；
- 两源叠加只产生"方向相长/相消"的宽缓瓣（空间尺度 = 源间距，米级渐变），**不存在随路径差振荡的条纹** → 屏幕上任意采样都是平滑梯度，**无高频可混叠**；
- 无镜象源、无应力近场修正 F(r)、无对数标尺展开 → 没有任何细密同心环或被放大的弱条纹；
- 早期版唯一的线性伪影是 `holeOcclusion` 的 X 形直线黑影（当前版已禁用该函数，sceneBuilder.js L581-585 注释）。

## 二、当前版摩尔纹的四个来源（按贡献排序）

当前版 `mps = √(|accE|²+|accQ|²)` 是**多源复相量和的波包包络**（sceneBuilder.js L409-555）。单源模长会消掉载波，但**多源之间的相位差仍然保留**——这正是干涉条纹的来源，也是摩尔纹的来源：

1. **多源相位干涉条纹（主因）**：条纹空间周期 `Λ = c_view/(f·|∇(r_i−r_j)|)`，最细处 Λ=c/(2f)。UI"波包频率"滑杆 0–30 Hz（默认 2 Hz）：f=2 → Λ≥8.75m 尚平滑；**f=8 → 2.2m（面板自注"几像素一条纹，观感是噪点/摩尔纹"）；f=30 → 0.58m**。16 个直达源 × 各自镜象源 = 几十套条纹系统交叉，形成拍频/摩尔外观。
2. **镜象源 Lloyd 条纹（默认开，uReflectOn=1）**：直达波与掌子面镜像波在掠射角下路径差梯度极大 → 面前条纹无限变细 → **必然欠采样走样**。早期版无反射，无此项。
3. **应力近场修正 F(r)=1+A·(r_nf/r)²（仅当前版）**：r_nf≈0.5m、A=2，每个炮孔周围 1~2m 内 F 从 3 陡降到 1 → 密集同心环，掠射视角呈锯齿环。
4. **等值线折线组（仅当前版，contourExtractor.js 新增）**：对带条纹的 CPU 场做 Marching Squares 提取，密度高时线族交叉即视觉摩尔纹（面板可关；Line2 本身有 AA）。

**放大器**：当前版新增对数标尺 + P99.9 动态满量程（uNormMode/uNormAutoScale）把早期版被线性色阶压进底色的弱条纹**展开到可见色域**——同样的条纹在早期版根本看不见。

## 三、关键发现：文档声称的 LOD 修复不在代码里

《理论优化说明_文献驱动.md》§6bis 声称已实现两层修复：
1. "载波波纹 LOD：屏幕空间导数估计相位变化率，波纹短于 ~1.5px 时混退到包络场"；
2. "离散色档边界 AA（bandCoordAA）"。

**实测当前代码**：`sceneBuilder.js` 中 **无任何 `fwidth`/`oscLOD`/`bandCoordAA`**（fwidth 唯一出现处是 L646 的注释"等值线不再由本 shader 用 fwidth 绘制"）；色档 floor() 硬切也确已移除（L637）。实际留下的只有 accE/accQ 双分量包络改写（消除了单源载波环与过零死黑），**源间干涉条纹没有任何屏幕空间抗混叠处理** → 掠射视角/高载波频率下摩尔纹依旧。文档与代码不符，需修正文档或补实现。

## 四、修复选项（待确认后实施）

| 方案 | 做法 | 效果 | 代价 |
|---|---|---|---|
| **A. 相干/非相干混合 LOD（推荐）** | 逐源 `fwidth(arrival)` 得屏幕梯度；条纹 rad/px ≈ `2πf·(g_i+g_j)/c`（取最强两源）；超过 Nyquist（≈π/2 rad/px）时把相干和 `√(|accE|²+|accQ|²)` 平滑混向非相干 RSS 和 `√(Σ A_s²)`——条纹淡出、包络量级保留 | 物理可分辨处保留真条纹，欠采样处自动退化为平滑云图，摩尔纹根除 | 着色器 +2 个累加器、每源 1 次 fwidth；O(nS) 不变 |
| B. 参数护栏 | UI 载波滑杆上限 30→8 Hz、默认 2 Hz 保持；对 F(r) 在掠射视角做 smooth 钳制 | 快速缓解 | 治标 |
| C. 等值线 | 密度默认下调一档；高频场自动跳档 | 消除线族摩尔 | 微 |

> 涉及文件：`sceneBuilder.js`（着色器 accE/accQ 块 + LUT 采样块）、`VibrationFieldPanel.vue`（滑杆范围）、`contourExtractor.js`（可选）。三项都支持开关回退（uCarrierHz=0 即纯包络，本就是当前口径之一）。
