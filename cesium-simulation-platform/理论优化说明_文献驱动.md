## 二、代码优化内容

### 1. 峰值场：全源同时叠加 → 时域错峰叠加（杨年华 2012 / Blair / 李洪超）

**旧口径（bound，保守上界）**：`peak(p)=|Σ_s A_s(r_s)·û_s|`——所有源不论延时全部同时到达，三角形不等式上界，延时错开时系统性高估（文献结论：线性叠加普遍大于实测）。

**新口径（history，默认）——时域错峰叠加峰值**：

```
peak(p) = max_s  e^(−D·arr_s) · | Σ_{s'≤s(延时序)} A_{s'}·e^(+D·arr_{s'})·û_{s'} |
arr_s = delay_s + r_s/c_view ,  D = β+β_v（与瞬时场同一时变衰减率）
```

- 各源按**延时升序**增量累加（O(nS·N)，无 O(nS²) 开销），在每个源自身到达时刻取合成幅值候选；因各源贡献到达后单调衰减，全局最大值必落在某源到达时刻，候选集完备；
- 物理行为：延时充分错开（>子波持时）→ 峰值≈最强单源幅值（韩亮实测：错峰降振率随延时先升后稳）；同段齐发 → 退化为同相叠加（上界）；
- **保持的数学性质**：单源时与旧口径完全一致；恒 ≤ bound 上界；seek/回拉确定性不变（仍是一次预计算 + O(N) 门控）。

**实现位置（三端同口径）**：
- 后端 `peak_ppv_envelope_multi(..., peak_method="history"|"bound")`（默认 history）；
- 前端 `_ensurePeakSlot` / `computeSurfacePeakField`（options.peakMethod，默认 history）；
- GPU 着色器 `uPeakHistory`（默认 1）：源 uniform **按延时升序**写入（applyFieldPhysics），片元内增量累加 B 并逐源取候选。

### 2. 雷管延期误差：常数 σ → 逐段概率模型（韩亮 2019）

- 后端新增 `detonator_delay_sigma(delay_ms, "nonel"|"electronic")` 与 `apply_detonator_jitter(sources, type, seed)`（确定性 Box–Muller，场景构建时调用一次）；
- 前端 `buildChargeSources` 新增 `jitterModel:'han2019'`：σ 逐源按名义延时取 `0.017·t+3.483 ms`（非电）或固定 1.2 ms（电子雷管），替代常数 jitter——**高段别（长延时）炮孔散射更大**，与实测一致，打破规则干涉条纹更真实。

### 3. 损伤/应力理论：动态泊松比 + 拉应力机制标注（梁瑞 2020 / 刘步青）

- 应力反演侧应力系数 b 与 von Mises 系数改用**动态泊松比 μ_d=0.8μ**（高应变率口径）：ν=0.25 时 b 由 0.333→0.286，σ_vm 约 −6.25%（`stress_field_from_ppv(dynamic_poisson=True)` 默认开；前端 `computeStressFieldFromPpv`、blastingManager 应力量程 `stressFactor`、GPU `stressFactor` 默认值同步）；
- 损伤阈值 `DAMAGE_THRESHOLDS_CMPS=(20,50,100,200) cm/s` 补充文献映射注释：fracture 档 100 cm/s 边界正对 Persson–Holmberg 700~1000 mm/s 损伤带，throw 档量级对应 Bauer & Calder 2540 mm/s 解体下限，micro_crack 档偏保守（显示口径）；
- 机制注释：梁瑞双孔斜交叠加表明孔间（β<arctanλ）切向受压、不易拉裂，外侧（β≥arctanλ）切向受拉剪裂——时域错峰叠加峰值场已能自然表达"同段齐发孔间增强、长延时孔间减弱"（刘步青实验结论），无需额外各项异性因子。

### 4. 损伤范围理论（新增）：固定 7m 上限 → 粉碎区/裂隙区半径

**旧口径**：`DAMAGE_MAX_RADIUS=7m` 固定显示上限（P0-2 调校值），与爆岩参数无关。

**新口径（theory，默认）——由孔壁初始压力与岩体动态强度推算**：

```
P_cJ = ρ_e·D²/4（γ=3）；P_b = 2·Z_r/(Z_r+Z_e)·P_cJ·(d_c/d_b)^(2γ)   （波阻抗透射+不耦合折减）
粉碎区：r_c = r_b·(P_b/σ_cd)^(1/3)                    （冲击波衰减 δ=3）
裂隙区：r_t = r_c·(b·σ_cd/σ_td)^(1/(2−b))             （应力波衰减 δ=2−b，b=μ_d/(1−μ_d)）
```

- 量级核对：42mm 隧道孔 r_t≈0.16m、250mm 露天孔 r_t≈0.92m——与文献"裂隙区≈10~20 倍装药半径"同量级；
- 损伤范围 = 各源裂隙区的**并集**（`dmin(p) ≤ r_t` 即损伤，孔间岩桥叠加增强由时域错峰峰值场自然表达，刘步青实验结论）；
- UI 滑块（damageMaxRadius）语义改为"只能收紧的上限"：`R_eff = min(UI, r_t)`；
- **可见性下限** `min_radius = 2×网格分辨率`（后端 WS 按 grid 实算、前端 1.5m 常数口径）：42mm 孔 r_t=0.16m 小于 0.75m 网格分辨率时，以 1.5m 下限保底，避免损伤区整体落入亚体素不可见（纯显示层保护，物理口径不变；离线精度场景传 `min_radius=0` 即纯理论）；
- 过渡宽度 `tau = min(1.5, 0.5·R_eff)`，防过渡带宽于半径把近源压暗；
- 实现位置：后端 `damage_zone_radius()` + `damage_zone_field(radius_model='theory')`（`blasting_ws.py` 两个损伤帧调用点已接线）；前端 `damageZoneRadius()` 镜像 + `blastingManager._effectiveDamageMaxRadius()`（本地模拟重建/setDamageBoundary/岩面着色三处同口径）。

### 6. 渲染与理论统一修复（损伤分区整屏空白的根因）

- **GPU 损伤淡出圈口径不一致（已修）**：着色器损伤分支的淡出旧实现按"片元到爆心 uBlastOrigin 的距离"画圈，而理论/后端/CPU 均按"到最近真实炮孔的距离 dmin"收束。损伤范围理论生效后 R_eff≈1.5m，该圈落在洞身/掌子面轮廓内 → 可视岩面 dmgFade 全 0 → **损伤分区模式整屏无着色**（用户截图实测）。已改为片元循环内累计 `dminSrc`（与 CPU dmin 同口径，不含镜像反射）。
- **范围上限计入炮孔群展开半径（已修）**：损伤区是各源裂隙区的并集，外包络 = r_t + 群展开半径（各源到掏槽质心的最大距离）。后端 `damage_zone_field`（由 sources 实算）与前端 `_effectiveDamageMaxRadius()` 均已计入——多孔设计下 R_eff 随布孔范围自适应，不再被单点 r_t 压扁。
- **形态学说明**：热力图（振速/应力模式）的瓣状非圆形结构来自多源矢量叠加干涉（相长/相消），三端同口径，属理论形态而非渲染错位；损伤分区模式本身为五档离散分区（Persson 工程分区），非连续色阶热力图。

### 6bis. 内壁视角"细线条/不平滑"的抗锯齿（渲染 LOD，已修）

同一套公式下，隧道内壁视角布满细线条、侧面视角却平滑饱满——原因是**采样**而非计算：内壁视角贴近爆源且斜视，载波波纹（视觉波长 λ≈4.4m）与干涉瓣的空间频率最高，逐像素采样欠采样后走样成摩尔纹/锯齿细环；侧面看的是远场低频区（体纹理另有三线性插值平滑）。MSAA 只平滑几何边、对片元级高频图案无效，故在着色器内做两层修复：

1. **载波波纹 LOD**：用爆心距探针的屏幕空间导数估计载波相位变化率（rad/px），波纹短于 ~1.5px 时按比例把瞬时场混退到子波包络场（新增 `accE` 包络累加器）——保留干涉瓣大形态、削去走样细环；远场/正视区域 oscLOD=1 完全不受影响；
2. **离散色档边界 AA**（`bandCoordAA`）：工业 N 档量化的 floor() 硬边界改用屏幕空间导数做 ~1px 过渡——档内纯色、边界单像素混合，保留工程离散色档观感、消除高频区"细横线/锯齿"。

### 5. 行为变化预期（渲染观感）

- 损伤/峰值模式：长延时（如 1450~3200 ms 逐孔起爆）场景下峰值场不再糊成"全源同时到达的大红团"，而是随波前逐段推进、峰值区跟随最强源衰减演化；峰值整体回落（约为旧口径的 30%~90%，取决于延时差与衰减率）；损伤范围收束到"炮孔群裂隙区并集"（R_eff = r_t + 群展开半径），贴着掌子面炮孔群分布而非铺满岩体；
- 瞬时振速/应力波前动画：不变（该路径本就是时域错峰叠加）；
- 若需对比旧口径，传 `peak_method="bound"`（后端）/ `peakMethod:'bound'`（前端）/ `uPeakHistory=0`（着色器）即可。

## 四、局限与后续建议

1. history 法的候选集假设"到达顺序≈延时顺序"（逐点路径时差 < 相邻源延时差时严格成立）；路径时差极大时峰值可能被轻微低估（仍 ≤ 上界、≥ 最强单源），如需严格可加逐点到达排序（代价 O(nS²·N)，不建议默认开启）。
2. FDTD 爆腔源网格欠解析问题（前份核验报告 ❌ 项）本轮未动，建议按报告第 5 节钳制 τ 或局部加密后另行实施。
3. 蒙特卡罗 95% 置信上限（李洪超口径）可作为后端离线报告功能：对 `apply_detonator_jitter` 采样 N 次各算 peak 取分位数——已具备全部构件，按需接线。
